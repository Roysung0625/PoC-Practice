# 업무영역 확인 필요

[전체 일람](../index.md)

분류 근거: 원본 사전 Name/Description + 주요 열/물리 FK 교차대조(문서 overlay 자동 규칙). 물리적 연결과 업무 의미의 확정은 구분합니다.

사전 의미와 주요 열/FK가 하나의 업무영역으로 합치하지 않아 추가 검토가 필요한 항목입니다.

관계 흐름 근거(실제 물리 FK의 자식 → 부모; 실행 시간 순서 아님):

- `a_registrationvalue.(a_registrationattribute_id)` → `a_registrationattribute.(a_registrationattribute_id)` (`aregattribute_aregvalue`).
- `ad_broadcastmessage.(notification_client_id)` → `ad_client.(ad_client_id)` (`notificationclient_adbroadcast`).
- `ad_broadcastmessage_trl.(ad_broadcastmessage_id)` → `ad_broadcastmessage.(ad_broadcastmessage_id)` (`adbroadcastmessage_adbroadcast`).
- `ad_broadcastmessage_trl.(ad_language)` → `ad_language.(ad_language)` (`adlanguage_adbroadcastmessaget`).
- `ad_client.(ad_language)` → `ad_language.(ad_language)` (`adlangu_adclient`).
- `ad_clientinfo.(c_chargefreight_id)` → `c_charge.(c_charge_id)` (`cchargefreight_adclientinfo`).
- `ad_clientinfo.(logo_id)` → `ad_image.(ad_image_id)` (`logo_adclientinfo`).
- `ad_clientinfo.(logoreport_id)` → `ad_image.(ad_image_id)` (`logoreport_adclientinfo`).
