# 입출금·은행·결제 배분 — 근거 기반 분류안·공식 분류 아님

[전체 일람](../index.md)

분류 근거: 원본 사전 Name/Description + 주요 열/물리 FK 교차대조(문서 overlay 자동 규칙). 물리적 연결과 업무 의미의 확정은 구분합니다.

입출금·은행 명세·현금·수금/지급 배분의 참조를 탐색합니다. 청구액과 입금액을 동일시하지 않습니다.

관계 흐름 근거(실제 물리 FK의 자식 → 부모; 실행 시간 순서 아님):

- `c_allocationhdr.(reversal_id)` → `c_allocationhdr.(c_allocationhdr_id)` (`reversal_callocationhdr`).
- `c_allocationline.(c_allocationhdr_id)` → `c_allocationhdr.(c_allocationhdr_id)` (`callocation_callocationline`).
- `c_allocationline.(c_banktransfer_id)` → `c_banktransfer.(c_banktransfer_id)` (`cbanktransfer_callocationline`).
- `c_allocationline.(c_cashline_id)` → `c_cashline.(c_cashline_id)` (`ccashline_callocationline`).
- `c_allocationline.(c_payment_id)` → `c_payment.(c_payment_id)` (`cpayment_callocationline`).
- `c_bankaccount.(c_bank_id)` → `c_bank.(c_bank_id)` (`cbank_cbankaccount`).
- `c_bankaccount_processor.(c_bankaccount_id)` → `c_bankaccount.(c_bankaccount_id)` (`cbankaccount_cbankaccountproce`).
- `c_bankaccount_processor.(c_paymentprocessor_id)` → `c_paymentprocessor.(c_paymentprocessor_id)` (`cpaymentprocessor_cbankaccount`).
