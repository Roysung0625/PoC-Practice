# 세금·원천징수 — 근거 기반 분류안·공식 분류 아님

[전체 일람](../index.md)

분류 근거: 원본 사전 Name/Description + 주요 열/물리 FK 교차대조(문서 overlay 자동 규칙). 물리적 연결과 업무 의미의 확정은 구분합니다.

세율·세금 구분·원천징수 및 문서 세금 항목의 참조를 탐색합니다.

관계 흐름 근거(실제 물리 FK의 자식 → 부모; 실행 시간 순서 아님):

- `c_bp_withholding.(c_withholding_id)` → `c_withholding.(c_withholding_id)` (`cwithholding_cbpwithholding`).
- `c_invoicetax.(c_tax_id)` → `c_tax.(c_tax_id)` (`ctax_cinvoicetax`).
- `c_invoicetax.(c_taxprovider_id)` → `c_taxprovider.(c_taxprovider_id)` (`ctaxprovider_cinvoicetax`).
- `c_ordertax.(c_tax_id)` → `c_tax.(c_tax_id)` (`ctax_cordertax`).
- `c_ordertax.(c_taxprovider_id)` → `c_taxprovider.(c_taxprovider_id)` (`ctaxprovider_cordertax`).
- `c_tax.(parent_tax_id)` → `c_tax.(c_tax_id)` (`ctax_parent`).
- `c_tax.(c_taxcategory_id)` → `c_taxcategory.(c_taxcategory_id)` (`ctaxcategory_ctax`).
- `c_tax.(c_taxprovider_id)` → `c_taxprovider.(c_taxprovider_id)` (`ctaxprovider_ctax`).
