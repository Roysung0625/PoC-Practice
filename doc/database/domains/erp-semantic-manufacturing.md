# 제조·BOM·소요 계획 — 근거 기반 분류안·공식 분류 아님

[전체 일람](../index.md)

분류 근거: 원본 사전 Name/Description + 주요 열/물리 FK 교차대조(문서 overlay 자동 규칙). 물리적 연결과 업무 의미의 확정은 구분합니다.

제조 지시·제품 구성·생산 행·소요 계획의 문서 및 구성 참조를 탐색합니다.

관계 흐름 근거(실제 물리 FK의 자식 → 부모; 실행 시간 순서 아님):

- `m_bomproduct.(m_bom_id)` → `m_bom.(m_bom_id)` (`mbom_mbomproduct`).
- `m_bomproduct.(m_bomalternative_id)` → `m_bomalternative.(m_bomalternative_id)` (`mbomalternative_mbomproduct`).
- `m_production.(pp_product_bom_id)` → `pp_product_bom.(pp_product_bom_id)` (`ppproductbom_mproduction`).
- `m_production.(reversal_id)` → `m_production.(m_production_id)` (`reversal_mproduction`).
- `m_productionline.(m_production_id)` → `m_production.(m_production_id)` (`mproduction_mproductionline`).
- `m_productionline.(m_productionplan_id)` → `m_productionplan.(m_productionplan_id)` (`mproductionplan_line`).
- `m_productionlinema.(m_productionline_id)` → `m_productionline.(m_productionline_id)` (`mproductionline_mplinema`).
- `m_productionplan.(m_production_id)` → `m_production.(m_production_id)` (`mproduction_plan`).
