# 상품·속성·가격·단위 — 근거 기반 분류안·공식 분류 아님

[전체 일람](../index.md)

분류 근거: 원본 사전 Name/Description + 주요 열/물리 FK 교차대조(문서 overlay 자동 규칙). 물리적 연결과 업무 의미의 확정은 구분합니다.

상품/서비스 기준·속성·가격표·단위의 참조를 탐색합니다. 상품 행이 매출 실적을 뜻하지는 않습니다.

관계 흐름 근거(실제 물리 FK의 자식 → 부모; 실행 시간 순서 아님):

- `a_asset_product.(m_attributesetinstance_id)` → `m_attributesetinstance.(m_attributesetinstance_id)` (`mattributesetinstance_aassetpr`).
- `a_asset_product.(m_product_id)` → `m_product.(m_product_id)` (`mproduct_aassetproduct`).
- `a_registrationproduct.(m_product_id)` → `m_product.(m_product_id)` (`mproduct_aregproduct`).
- `c_rfq_topicsubscriberonly.(m_product_category_id)` → `m_product_category.(m_product_category_id)` (`mprodcategory_crfqtsubonly`).
- `c_rfq_topicsubscriberonly.(m_product_id)` → `m_product.(m_product_id)` (`mproduct_crfqtsubonly`).
- `c_servicelevel.(m_product_id)` → `m_product.(m_product_id)` (`mproduct_cservicelevel`).
- `c_servicelevelline.(c_servicelevel_id)` → `c_servicelevel.(c_servicelevel_id)` (`cservicelevel_line`).
- `c_uom_conversion.(c_uom_to_id)` → `c_uom.(c_uom_id)` (`c_uomconversionto`).
