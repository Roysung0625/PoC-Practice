# 인사·급여 — 근거 기반 분류안·공식 분류 아님

[전체 일람](../index.md)

분류 근거: 원본 사전 Name/Description + 주요 열/물리 FK 교차대조(문서 overlay 자동 규칙). 물리적 연결과 업무 의미의 확정은 구분합니다.

급여 계약·사원·개념·기간·이동/계산 기록의 연결을 탐색합니다.

관계 흐름 근거(실제 물리 FK의 자식 → 부모; 실행 시간 순서 아님):

- `hr_attribute.(hr_concept_id)` → `hr_concept.(hr_concept_id)` (`hrconcept_hrattribute`).
- `hr_attribute.(hr_department_id)` → `hr_department.(hr_department_id)` (`hrdepartment_hrattribute`).
- `hr_attribute.(hr_employee_id)` → `hr_employee.(hr_employee_id)` (`hremployee_hrattribute`).
- `hr_attribute.(hr_job_id)` → `hr_job.(hr_job_id)` (`hrjob_hrattribute`).
- `hr_attribute.(hr_payroll_id)` → `hr_payroll.(hr_payroll_id)` (`hrpayroll_hrattribute`).
- `hr_concept.(hr_concept_category_id)` → `hr_concept_category.(hr_concept_category_id)` (`hrconceptcategory_hrconcept`).
- `hr_concept.(hr_department_id)` → `hr_department.(hr_department_id)` (`hrdepartment_hrconcept`).
- `hr_concept.(hr_job_id)` → `hr_job.(hr_job_id)` (`hrjob_hrconcept`).
