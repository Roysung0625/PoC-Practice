# 웹 콘텐츠·미디어 — 근거 기반 분류안·공식 분류 아님

[전체 일람](../index.md)

분류 근거: 원본 사전 Name/Description + 주요 열/물리 FK 교차대조(문서 overlay 자동 규칙). 물리적 연결과 업무 의미의 확정은 구분합니다.

콘텐츠 컨테이너·스테이지·템플릿·미디어 배포/뉴스의 참조를 탐색합니다.

관계 흐름 근거(실제 물리 FK의 자식 → 부모; 실행 시간 순서 아님):

- `cm_container.(cm_containerlink_id)` → `cm_container.(cm_container_id)` (`cmcontainer_cmcontainerlink`).
- `cm_container.(cm_template_id)` → `cm_template.(cm_template_id)` (`cmtemplate_cmcontainer`).
- `cm_container.(cm_webproject_id)` → `cm_webproject.(cm_webproject_id)` (`cmwebproject_cmcontainer`).
- `cm_container_element.(cm_container_id)` → `cm_container.(cm_container_id)` (`cmcontainer_cmcontainerelement`).
- `cm_container_trl.(cm_container_id)` → `cm_container.(cm_container_id)` (`cmcontainer_cmcontainertrl`).
- `cm_container_url.(cm_container_id)` → `cm_container.(cm_container_id)` (`cmcontainer_cmcontainerurl`).
- `cm_containerttable.(cm_container_id)` → `cm_container.(cm_container_id)` (`cmcontainer_cmcontainerttable`).
- `cm_cstage.(cm_cstagelink_id)` → `cm_cstage.(cm_cstage_id)` (`cmcstage_cmcstagelink`).
