# 보고서·성과·대시보드 — 근거 기반 분류안·공식 분류 아님

[전체 일람](../index.md)

분류 근거: 원본 사전 Name/Description + 주요 열/물리 FK 교차대조(문서 overlay 자동 규칙). 물리적 연결과 업무 의미의 확정은 구분합니다.

보고서 정의·성과 측정·차트/대시보드 구성의 참조를 탐색합니다. 표시 결과의 정확성 검증은 별도입니다.

관계 흐름 근거(실제 물리 FK의 자식 → 부모; 실행 시간 순서 아님):

- `ad_chart_trl.(ad_chart_id)` → `ad_chart.(ad_chart_id)` (`adchart_adcharttrl`).
- `ad_chartdatasource.(ad_chart_id)` → `ad_chart.(ad_chart_id)` (`adchart_adchartdatasource`).
- `ad_chartdatasource_trl.(ad_chartdatasource_id)` → `ad_chartdatasource.(ad_chartdatasource_id)` (`adchartdatasourceadchartdatas`).
- `ad_process.(ad_reportview_id)` → `ad_reportview.(ad_reportview_id)` (`adreportview_adprocess`).
- `ad_process_trl.(ad_process_id)` → `ad_process.(ad_process_id)` (`ad_process_ad_process_trl`).
- `ad_reportview_col.(ad_reportview_id)` → `ad_reportview.(ad_reportview_id)` (`adreportview_col`).
- `ad_reportview_column.(ad_reportview_id)` → `ad_reportview.(ad_reportview_id)` (`adreportview_adreportviewcolum`).
- `pa_achievement.(pa_measure_id)` → `pa_measure.(pa_measure_id)` (`pameasure_paachievement`).
