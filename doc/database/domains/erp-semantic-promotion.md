# 프로모션·마케팅 — 근거 기반 분류안·공식 분류 아님

[전체 일람](../index.md)

분류 근거: 원본 사전 Name/Description + 주요 열/물리 FK 교차대조(문서 overlay 자동 규칙). 물리적 연결과 업무 의미의 확정은 구분합니다.

프로모션 조건/보상·상품 그룹·캠페인의 설정 참조를 탐색합니다. 실제 할인 적용 여부를 보장하지 않습니다.

관계 흐름 근거(실제 물리 FK의 자식 → 부모; 실행 시간 순서 아님):

- `c_campaign.(c_channel_id)` → `c_channel.(c_channel_id)` (`cchannel_ccampaign`).
- `c_campaign_trl.(c_campaign_id)` → `c_campaign.(c_campaign_id)` (`ccampaign_ccampaigntrl`).
- `m_promotion.(c_campaign_id)` → `c_campaign.(c_campaign_id)` (`ccampaign_mpromotion`).
- `m_promotiondistribution.(m_promotion_id)` → `m_promotion.(m_promotion_id)` (`mpromotion_mpromotiondistribut`).
- `m_promotiondistribution.(m_promotionline_id)` → `m_promotionline.(m_promotionline_id)` (`mpromotionline_mpromotiondistr`).
- `m_promotiongroupline.(m_promotiongroup_id)` → `m_promotiongroup.(m_promotiongroup_id)` (`mpromotiongroup_mpromotiongrou`).
- `m_promotionline.(m_promotion_id)` → `m_promotion.(m_promotion_id)` (`mpromotion_mpromotionline`).
- `m_promotionline.(m_promotiongroup_id)` → `m_promotiongroup.(m_promotiongroup_id)` (`mpromotiongroup_mpromotionline`).
