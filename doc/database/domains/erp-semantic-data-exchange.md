# 데이터 연계·가져오기·내보내기 — 근거 기반 분류안·공식 분류 아님

[전체 일람](../index.md)

분류 근거: 원본 사전 Name/Description + 주요 열/물리 FK 교차대조(문서 overlay 자동 규칙). 물리적 연결과 업무 의미의 확정은 구분합니다.

원본 사전이 명시하는 적재 준비·교환 형식·전송 처리기와 그 실행 기록을 탐색합니다.

관계 흐름 근거(실제 물리 FK의 자식 → 부모; 실행 시간 순서 아님):

- `ad_importtemplateaccess.(ad_importtemplate_id)` → `ad_importtemplate.(ad_importtemplate_id)` (`adimporttemplate_adimporttempl`).
- `ad_replication.(ad_replicationstrategy_id)` → `ad_replicationstrategy.(ad_replicationstrategy_id)` (`adreplicationstrategy_adrep`).
- `ad_replication_log.(ad_replication_run_id)` → `ad_replication_run.(ad_replication_run_id)` (`adreplicationrun_adreplog`).
- `ad_replication_log.(ad_replicationtable_id)` → `ad_replicationtable.(ad_replicationtable_id)` (`adreptable_adreplog`).
- `ad_replication_run.(ad_replication_id)` → `ad_replication.(ad_replication_id)` (`adreplication_adreprun`).
- `ad_replicationstrategy.(exp_processor_id)` → `exp_processor.(exp_processor_id)` (`expprocessor_adreplicationstra`).
- `ad_replicationtable.(ad_replicationstrategy_id)` → `ad_replicationstrategy.(ad_replicationstrategy_id)` (`adrepstrategy_adreptable`).
- `exp_processor.(exp_processor_type_id)` → `exp_processor_type.(exp_processor_type_id)` (`expprocessortype_expprocessor`).
