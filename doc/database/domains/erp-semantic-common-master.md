# 테넌트·조직·통화·지역·달력 기준 — 근거 기반 분류안·공식 분류 아님

[전체 일람](../index.md)

분류 근거: 원본 사전 Name/Description + 주요 열/물리 FK 교차대조(문서 overlay 자동 규칙). 물리적 연결과 업무 의미의 확정은 구분합니다.

테넌트/조직·통화/환산·지리·달력·문서 유형 등 여러 업무에서 공유하는 기준 참조를 탐색합니다.

관계 흐름 근거(실제 물리 FK의 자식 → 부모; 실행 시간 순서 아님):

- `ad_orginfo.(parent_org_id)` → `ad_org.(ad_org_id)` (`adorgparent_adorginfo`).
- `ad_orginfo.(ad_orgtype_id)` → `ad_orgtype.(ad_orgtype_id)` (`adorgtype_adorginfo`).
- `ad_orginfo.(c_calendar_id)` → `c_calendar.(c_calendar_id)` (`ccalendar_adorginfo`).
- `c_chargetype_doctype.(c_doctype_id)` → `c_doctype.(c_doctype_id)` (`cdoctype_cchargetypedoctype`).
- `c_city.(c_country_id)` → `c_country.(c_country_id)` (`ccountry_ccity`).
- `c_city.(c_region_id)` → `c_region.(c_region_id)` (`cregion_ccity`).
- `c_conversion_rate.(c_currency_id_to)` → `c_currency.(c_currency_id)` (`c_currencyconvrateto`).
- `c_conversion_rate.(c_conversiontype_id)` → `c_conversiontype.(c_conversiontype_id)` (`cconversiontype_cconvrate`).
