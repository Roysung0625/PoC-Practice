# 자산·감가상각 — 근거 기반 분류안·공식 분류 아님

[전체 일람](../index.md)

분류 근거: 원본 사전 Name/Description + 주요 열/물리 FK 교차대조(문서 overlay 자동 규칙). 물리적 연결과 업무 의미의 확정은 구분합니다.

자산 식별·취득/처분·감가상각 설정과 관련 금액/기간 기록을 탐색합니다.

관계 흐름 근거(실제 물리 FK의 자식 → 부모; 실행 시간 순서 아님):

- `a_asset.(a_asset_class_id)` → `a_asset_class.(a_asset_class_id)` (`aassetclass_aasset`).
- `a_asset.(a_asset_group_id)` → `a_asset_group.(a_asset_group_id)` (`aassetgroup_aasset`).
- `a_asset.(a_asset_type_id)` → `a_asset_type.(a_asset_type_id)` (`aassettype_aasset`).
- `a_asset.(a_parent_asset_id)` → `a_asset.(a_asset_id)` (`aparentasset_aasset`).
- `a_asset_addition.(a_asset_id)` → `a_asset.(a_asset_id)` (`aasset_aassetaddition`).
- `a_asset_change.(a_asset_addition_id)` → `a_asset_addition.(a_asset_addition_id)` (`aaaddition_aachange`).
- `a_asset_change.(a_asset_retirement_id)` → `a_asset_retirement.(a_asset_retirement_id)` (`aaretirement_aachange`).
- `a_asset_change.(a_asset_id)` → `a_asset.(a_asset_id)` (`aasset_aassetchange`).
