# 프로세스·스케줄·시스템 운영 — 근거 기반 분류안·공식 분류 아님

[전체 일람](../index.md)

분류 근거: 원본 사전 Name/Description + 주요 열/물리 FK 교차대조(문서 overlay 자동 규칙). 물리적 연결과 업무 의미의 확정은 구분합니다.

프로세스 실행 정의·스케줄·시스템 설정·알림/오류 기록의 참조를 탐색합니다.

관계 흐름 근거(실제 물리 FK의 자식 → 부모; 실행 시간 순서 아님):

- `ad_alert.(ad_alertprocessor_id)` → `ad_alertprocessor.(ad_alertprocessor_id)` (`calertprocessor_adalert`).
- `ad_alertprocessor.(ad_schedule_id)` → `ad_schedule.(ad_schedule_id)` (`adschedule_adalertprocessor`).
- `ad_alertprocessorlog.(ad_alertprocessor_id)` → `ad_alertprocessor.(ad_alertprocessor_id)` (`calertprocessor_log`).
- `ad_alertrecipient.(ad_alert_id)` → `ad_alert.(ad_alert_id)` (`adalert_adalertrecipient`).
- `ad_alertrule.(ad_alert_id)` → `ad_alert.(ad_alert_id)` (`adaltert_aralertrule`).
- `ad_process_para_trl.(ad_process_para_id)` → `ad_process_para.(ad_process_para_id)` (`adprocpara_adprocparatrl`).
- `ad_scheduler.(ad_schedule_id)` → `ad_schedule.(ad_schedule_id)` (`adschedule_adscheduler`).
- `ad_scheduler_para.(ad_process_para_id)` → `ad_process_para.(ad_process_para_id)` (`adprocesspara_adschedulerpara`).
