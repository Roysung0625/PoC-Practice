## 재검사

프로젝트 루트의 PowerShell에서 실행합니다. 기본 명령은 읽기 전용 검사입니다. 현재 `.local/app.env`의 읽기 전용 연결을 내부에서 읽지만 DSN/비밀번호는 출력하지 않습니다.

```powershell
.\.venv\Scripts\python.exe doc/database/audit_database_docs.py --offline
```

`--offline`은 2026-11-03T23:33:22+09:00에 수집한 고정 메타데이터로 집합·문서·분류 근거만 재검사하며 DB에 연결하지 않습니다. 이번 의미 분류 overlay 작업도 이 방식으로 수행했습니다. 옵션 없는 기본 명령은 현재 DB 메타데이터를 새로 읽어 비교하므로 이번 작업에서 다시 실행하지 않았습니다. 스키마·문서 범위가 바뀌면 먼저 차이를 검토하고, 새 운영 문서/색인만 갱신할 때 `--write`를 사용합니다. 이 옵션도 `docs/database/idempiere`와 기존 스냅샷에 쓰지 않습니다. 기존 검증기의 VERIFICATION.md 쓰기는 검사기 내부에서 차단하며 원본 파일 해시를 유지합니다. 일람의 숫자를 맞추기 위해 누락 대상이나 오래된 파일을 조용히 제외하지 않습니다.

이번 PASS는 고정 메타데이터의 구조·집합·링크와 분류 근거 재계산입니다. 사용자 공통 지침 7.3에 따라 사전 의미와 주요 열/FK를 함께 기록한 근거 기반 분류안을 제시했지만 사람이 공식 검증한 업무 분류는 아닙니다. 남은 182개는 확인 필요입니다. 관계형 테이블의 데이터 내용, 전체 ERP 의미의 전문가 승인, JSON 내부 값과 파일 존재의 전체 점검, 현재 클라우드 KV/검색 엔진의 실행 확인을 대신하지 않습니다.
