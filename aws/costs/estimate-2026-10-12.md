## 견적 대상 흐름

```text
Windows 챗봇 -> AgentCore Agent + Bedrock -> Lambda SQL Tool
  -> SQS -> Windows 수신기 -> 로컬 FastAPI -> PostgreSQL
  -> Windows 수신기가 DynamoDB에 결과 기록
  -> Lambda가 결과를 읽어 같은 도구 호출에서 반환
  -> Agent가 결과 설명 -> Windows 챗봇
```

Agent가 DynamoDB를 직접 폴링하지 않습니다. Lambda 실행 시간에는 로컬 SQL 결과를 기다리는 시간이 포함됩니다.
Windows에서 AWS로 HTTPS 연결을 시작하는 방식입니다. 챗봇, SQL API, PostgreSQL, 표·그래프 렌더링은 기존 Windows PC에서 실행하는 가정입니다.

## 입력값과 산식 기록

### Bedrock

Calculator의 분당 요청 수와 일일 사용 시간 필드는 정수만 허용하므로, 월 총 토큰이 같은 입력으로 환산했습니다.

- 실제 가정: `1,500질문 × 2회 = 3,000회 모델 호출`, 입력 9,000,000 / 출력 1,500,000토큰.
- Calculator 입력: 분당 1요청, 하루 1시간, 요청당 입력 5,000 / 출력 834토큰.
- 계산기 월 환산: `1 × 60 × 1 × 30 = 1,800`개의 계산용 요청. 실제 모델 호출 수를 뜻하지 않습니다.
- 환산 결과: 입력 9,000,000 / 출력 1,501,200토큰. 출력은 정수 반올림 때문에 1,200토큰(0.08%) 많습니다.
- 화면 단가: 입력 100만 토큰당 0.072 USD, 출력 100만 토큰당 0.288 USD.
- 비용: `9 × 0.072 + 1.5012 × 0.288 = 1.0803456 USD` → 표시 1.08 USD.

### AgentCore

- CPU: `1,500 × 105초 × (1 - 0.9) × 1 vCPU ÷ 3,600 × 0.0895 USD = 약 0.39156 USD`.
- 메모리: `1,500 × 105초 × 0.5 GB ÷ 3,600 × 0.00945 USD = 약 0.20672 USD`.
- 합계 약 0.59828 USD → 표시 0.60 USD.
- `idleRuntimeSessionTimeout=60`을 설정할 계획이라는 조건입니다. 아직 배포·설정하지 않았습니다.
- AWS 문서는 유휴 제한 기본값 900초, 설정 가능 최솟값 60초, 종료 최대 15초를 설명합니다. [Runtime 수명 주기 문서](https://docs.aws.amazon.com/bedrock-agentcore/latest/devguide/runtime-lifecycle-settings.html)
- Runtime 세대와 실제 메모리 회수·세션 종료 동작에 따라 비용이 달라질 수 있으므로 배포 시 확인합니다. 이 견적은 확인한 Calculator Runtime 산식을 사용합니다.

### Lambda와 Windows 연결

- Lambda: `1,500 × 10초 × 0.25 GB × 0.0000166667 USD + 1,500 × 0.0000002 USD = 약 0.06280 USD`.
- SQS 빈 수신 상한 가정: `730시간 × 3,600초 ÷ 20초 = 131,400요청`.
- SQS 작업 처리: `1,500 × (전송 + 수신 + 삭제) = 4,500요청`.
- 합계 135,900요청, 100만 요청당 0.40 USD → 약 0.05436 USD. 빈 수신과 작업 수신을 별도로 더한 보수적 가정입니다.
- DynamoDB: 질문당 상태·결과 쓰기 4회와 Lambda 결과 읽기 10회. 평균 항목 4 KB로 계산기에 입력했으며, 쓰기 요청 수와 쓰기 과금 단위는 서로 다릅니다.
- 상시 heartbeat 쓰기, 대규모 SQL 결과, 반복 장애·재시도, DLQ 누적은 기본 사용량에 포함하지 않았습니다.

### 로그·저장·송신

- CloudWatch: 로그 입력 `0.1 GB × 0.76 USD`, 압축 저장 약 0.000495 USD, 알람 `2 × 0.10 USD` → 약 0.276495 USD.
- 실제 운영 로그 보관은 7일 등을 선택할 수 있지만 견적에는 1개월을 넣었습니다. 고급 관측·추적·유료 대시보드는 포함하지 않았습니다.
- S3: 저장 `0.5 × 0.025 USD`, PUT 등 `100 × 0.0000047 USD`, GET 등 `1,000 × 0.00000037 USD` → 약 0.01334 USD.
- 인터넷 송신: `1 GB × 0.114 USD = 0.114 USD`. 다른 서비스의 전송량에는 중복 입력하지 않았습니다.
- Calculator 화면은 인터넷 송신 첫 100 GB 무료 혜택을 사용자가 직접 입력에 반영하도록 안내합니다. 이번 견적은 무료 혜택이 다른 사용량으로 소진된 경우에도 비교할 수 있도록 차감하지 않았습니다.

## 가정이 달라질 때

다음은 Calculator에서 확인한 단가로 별도 산술 계산한 민감도이며, 추가 Calculator 견적을 만든 것은 아닙니다.

| 변화 | 영향 |
| --- | --- |
| 질문 수는 같고 입력·출력 토큰이 각각 10배 | Bedrock 약 1.08 → 10.80 USD/월. 다른 조건이 같다면 전체 약 11.93 USD/월 |
| Lambda 평균 실행 10초 → 60초 | Lambda만 약 0.063 → 0.375 USD/월. Agent 세션과 DynamoDB 읽기도 늘 수 있으므로 전체 증가분은 이보다 큼 |
| Agent 유휴 제한 60초 → 기본값 900초 | CPU 사용은 같고 메모리를 계속 보유한다고 계산하면 AgentCore 약 0.60 → 2.25 USD/월, 전체 약 3.86 USD/월 |

이전 Nova Lite 구성에서는 **월 5 USD 정도를 관리 기준**으로 제안했습니다. 이는 요금 상한이 아니며, 현재 DeepSeek V3.2 + Titan 구성의 관리 예산은 새 견적을 기준으로 다시 정해야 합니다.

## 범위와 검증 경계

- 포함: 모델 추론, Agent 실행, Lambda 결과 대기, SQS 수신, DynamoDB 결과 교환, 로그·알람, 배포 파일, 인터넷 송신.
- 이 구성에서는 VPN, NAT Gateway, EC2, RDS, API Gateway를 사용하지 않는다고 가정하여 입력하지 않았습니다.
- AgentCore Gateway·장기 Memory·Browser·Code Interpreter·Guardrails·Knowledge Bases 등 선택 기능을 넣지 않았습니다. Agent 코드에서 AWS SDK로 Lambda를 직접 호출하는 도구를 가정합니다.
- 기존 Windows PC의 전기·인터넷·디스크·라이선스, 개발 인건비, 유료 AWS Support, 고객 관리 KMS 키·별도 Secrets Manager 등 추가 선택은 제외입니다.
- AWS 계정의 현재 청구액·크레딧 잔액·무료 혜택 자격을 조회한 결과가 아닙니다. 기존 다른 리소스의 비용이 있으면 별도로 합산해야 합니다.
- 모델의 SQL 정확도와 실제 평균 지연은 아직 검증하지 않았습니다. 이번 작업에서 AWS 인프라를 생성하거나 유료 모델을 실행하지 않았습니다.
- 구축 후 토큰 수, Lambda Duration, Agent 활성 CPU·메모리·세션 수명, SQS 요청 수, DynamoDB 요청·항목 크기, 로그량을 측정해 견적을 갱신합니다.
