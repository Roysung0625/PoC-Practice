# 출하·입고·반품·배송 — 근거 기반 분류안·공식 분류 아님

[전체 일람](../index.md)

분류 근거: 원본 사전 Name/Description + 주요 열/물리 FK 교차대조(문서 overlay 자동 규칙). 물리적 연결과 업무 의미의 확정은 구분합니다.

출하/입고·이동·반품·배송/분배의 헤더/상세 참조를 탐색합니다. 물리 FK 화살표를 시간 순서로 해석하지 않습니다.

관계 흐름 근거(실제 물리 FK의 자식 → 부모; 실행 시간 순서 아님):

- `ad_package_exp_detail.(ad_package_exp_id)` → `ad_package_exp.(ad_package_exp_id)` (`adpackageexp_adpackageexpdetai`).
- `ad_package_imp.(ad_package_imp_proc_id)` → `ad_package_imp_proc.(ad_package_imp_proc_id)` (`adpackageimpproc_adpackageimp`).
- `ad_package_imp_detail.(ad_package_imp_id)` → `ad_package_imp.(ad_package_imp_id)` (`adpackageimp_adpackageimpdetai`).
- `dd_networkdistributionline.(dd_networkdistribution_id)` → `dd_networkdistribution.(dd_networkdistribution_id)` (`ddnetworkdistribution_ddnetwor`).
- `dd_networkdistributionline.(m_shipper_id)` → `m_shipper.(m_shipper_id)` (`mshipper_ddnetworkdistribution`).
- `dd_orderline.(m_shipper_id)` → `m_shipper.(m_shipper_id)` (`mshipper_ddorderline`).
- `m_distributionlistline.(m_distributionlist_id)` → `m_distributionlist.(m_distributionlist_id)` (`mdistributionlist_line`).
- `m_distributionrunline.(m_distributionlist_id)` → `m_distributionlist.(m_distributionlist_id)` (`mdistributionlist_runline`).
