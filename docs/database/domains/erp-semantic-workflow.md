# 워크플로 정의·실행 — 근거 기반 분류안·공식 분류 아님

[전체 일람](../index.md)

분류 근거: 원본 사전 Name/Description + 주요 열/물리 FK 교차대조(문서 overlay 자동 규칙). 물리적 연결과 업무 의미의 확정은 구분합니다.

사전에서 workflow로 설명한 노드·전이·책임·실행 활동의 참조를 탐색합니다.

관계 흐름 근거(실제 물리 FK의 자식 → 부모; 실행 시간 순서 아님):

- `ad_wf_activity.(ad_wf_node_id)` → `ad_wf_node.(ad_wf_node_id)` (`adwfnode_adwfactivity`).
- `ad_wf_activity.(ad_wf_process_id)` → `ad_wf_process.(ad_wf_process_id)` (`adwfprocess_adwfactivity`).
- `ad_wf_activity.(ad_wf_responsible_id)` → `ad_wf_responsible.(ad_wf_responsible_id)` (`adwfresponsible_adwfactivity`).
- `ad_wf_activity.(ad_workflow_id)` → `ad_workflow.(ad_workflow_id)` (`adworkflow_adwfactivity`).
- `ad_wf_activityapprover.(ad_wf_activity_id)` → `ad_wf_activity.(ad_wf_activity_id)` (`adwfactivity_adwfactivityappro`).
- `ad_wf_activityresult.(ad_wf_activity_id)` → `ad_wf_activity.(ad_wf_activity_id)` (`adwfactivity_adwfactresult`).
- `ad_wf_block.(ad_workflow_id)` → `ad_workflow.(ad_workflow_id)` (`adworkflow_adwfblock`).
- `ad_wf_eventaudit.(ad_wf_node_id)` → `ad_wf_node.(ad_wf_node_id)` (`adwfnode_adwfeventaudit`).
