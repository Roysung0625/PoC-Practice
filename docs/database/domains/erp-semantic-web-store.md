# 웹 상점·POS·웹 접점 — 근거 기반 분류안·공식 분류 아님

[전체 일람](../index.md)

분류 근거: 원본 사전 Name/Description + 주요 열/물리 FK 교차대조(문서 overlay 자동 규칙). 물리적 연결과 업무 의미의 확정은 구분합니다.

웹 상점/장바구니·POS·접점 카운터/메뉴의 참조를 탐색합니다.

관계 흐름 근거(실제 물리 FK의 자식 → 부모; 실행 시간 순서 아님):

- `c_pos.(c_poskeylayout_id)` → `c_poskeylayout.(c_poskeylayout_id)` (`cposkeylayout_cpos`).
- `c_pos.(osk_keylayout_id)` → `c_poskeylayout.(c_poskeylayout_id)` (`oskkeylayout_cpos`).
- `c_pos.(osnp_keylayout_id)` → `c_poskeylayout.(c_poskeylayout_id)` (`osnpkeylayout_cpos`).
- `c_poskey.(c_poskeylayout_id)` → `c_poskeylayout.(c_poskeylayout_id)` (`cposkeylayout_c_poskey`).
- `c_poskey.(subkeylayout_id)` → `c_poskeylayout.(c_poskeylayout_id)` (`subkeylayout_cposkey`).
- `c_pospayment.(c_postendertype_id)` → `c_postendertype.(c_postendertype_id)` (`cpostendertype_cpospayment`).
- `w_advertisement.(w_clickcount_id)` → `w_clickcount.(w_clickcount_id)` (`wclickcount_wadvertisement`).
- `w_advertisement.(w_countercount_id)` → `w_countercount.(w_countercount_id)` (`wcountercount_wadvertisement`).
