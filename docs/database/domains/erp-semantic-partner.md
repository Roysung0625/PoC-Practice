# 거래처·연락처·주소 — 근거 기반 분류안·공식 분류 아님

[전체 일람](../index.md)

분류 근거: 원본 사전 Name/Description + 주요 열/물리 FK 교차대조(문서 overlay 자동 규칙). 물리적 연결과 업무 의미의 확정은 구분합니다.

거래처·고객/공급자 역할·주소/연락처의 기준 참조를 탐색합니다.

관계 흐름 근거(실제 물리 FK의 자식 → 부모; 실행 시간 순서 아님):

- `c_addresstransaction.(c_addressvalidation_id)` → `c_addressvalidation.(c_addressvalidation_id)` (`caddressvalidation_caddresstra`).
- `c_addresstransaction.(c_location_id)` → `c_location.(c_location_id)` (`clocation_caddresstransaction`).
- `c_addressvalidation.(c_addressvalidationcfg_id)` → `c_addressvalidationcfg.(c_addressvalidationcfg_id)` (`caddressvalidationcfg_caddress`).
- `c_bp_relation.(c_bpartner_id)` → `c_bpartner.(c_bpartner_id)` (`cbpartner_cbprelation`).
- `c_bp_relation.(c_bpartnerrelation_id)` → `c_bpartner.(c_bpartner_id)` (`cbpartner_cbprelationbp`).
- `c_bp_relation.(c_bpartner_location_id)` → `c_bpartner_location.(c_bpartner_location_id)` (`cbplocation_cbprelation`).
- `c_bp_relation.(c_bpartnerrelation_location_id)` → `c_bpartner_location.(c_bpartner_location_id)` (`cbplocation_cbprelationbp`).
- `c_bp_shippingacct.(c_bpartner_id)` → `c_bpartner.(c_bpartner_id)` (`cbpartner_cbpshippingacct`).
