# 프로젝트·활동·작업 — 근거 기반 분류안·공식 분류 아님

[전체 일람](../index.md)

분류 근거: 원본 사전 Name/Description + 주요 열/물리 FK 교차대조(문서 overlay 자동 규칙). 물리적 연결과 업무 의미의 확정은 구분합니다.

프로젝트/단계/작업·업무 활동과 예산/수량의 참조를 탐색합니다.

관계 흐름 근거(실제 물리 FK의 자식 → 부모; 실행 시간 순서 아님):

- `c_activity_trl.(c_activity_id)` → `c_activity.(c_activity_id)` (`cactivity_cactivitytrl`).
- `c_phase.(c_projecttype_id)` → `c_projecttype.(c_projecttype_id)` (`cprojecttype_cphase`).
- `c_project.(c_activity_id)` → `c_activity.(c_activity_id)` (`cactivity_cproject`).
- `c_project.(c_phase_id)` → `c_phase.(c_phase_id)` (`cphase_cproject`).
- `c_project.(c_projecttype_id)` → `c_projecttype.(c_projecttype_id)` (`cprojecttype_cproject`).
- `c_projectissue.(c_project_id)` → `c_project.(c_project_id)` (`cproject_cprojectissue`).
- `c_projectissue.(reversal_id)` → `c_projectissue.(c_projectissue_id)` (`reversal_cprojectissue`).
- `c_projectissuema.(c_projectissue_id)` → `c_projectissue.(c_projectissue_id)` (`cprojectissue_cprojectissuema`).
