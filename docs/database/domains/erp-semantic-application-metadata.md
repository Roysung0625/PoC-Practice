# 애플리케이션 사전·화면·서식 — 근거 기반 분류안·공식 분류 아님

[전체 일람](../index.md)

분류 근거: 원본 사전 Name/Description + 주요 열/물리 FK 교차대조(문서 overlay 자동 규칙). 물리적 연결과 업무 의미의 확정은 구분합니다.

애플리케이션 사전의 테이블/열·화면/필드·선택값·출력 서식 정의를 탐색합니다.

관계 흐름 근거(실제 물리 FK의 자식 → 부모; 실행 시간 순서 아님):

- `ad_attribute.(ad_reference_id)` → `ad_reference.(ad_reference_id)` (`adreference_adattribute`).
- `ad_attribute.(ad_reference_value_id)` → `ad_reference.(ad_reference_id)` (`adreferencevalue_adattribute`).
- `ad_attribute.(ad_table_id)` → `ad_table.(ad_table_id)` (`adtable_adattribute`).
- `ad_attribute.(ad_val_rule_id)` → `ad_val_rule.(ad_val_rule_id)` (`advalrule_adattribute`).
- `ad_color_trl.(ad_color_id)` → `ad_color.(ad_color_id)` (`adcolor_adcolortrl`).
- `ad_column.(ad_element_id)` → `ad_element.(ad_element_id)` (`ad_element_ad_column`).
- `ad_column.(ad_reference_id)` → `ad_reference.(ad_reference_id)` (`ad_reference_columndatatype`).
- `ad_column.(ad_reference_value_id)` → `ad_reference.(ad_reference_id)` (`ad_reference_columnvalue`).
