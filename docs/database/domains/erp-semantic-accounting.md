# 회계·원장·예산 — 근거 기반 분류안·공식 분류 아님

[전체 일람](../index.md)

분류 근거: 원본 사전 Name/Description + 주요 열/물리 FK 교차대조(문서 overlay 자동 규칙). 물리적 연결과 업무 의미의 확정은 구분합니다.

회계 스키마·계정/차원·분개·예산·회계 사실의 참조를 탐색합니다. 전기 실행이나 잔액 정확성을 검증한 분류는 아닙니다.

관계 흐름 근거(실제 물리 FK의 자식 → 부모; 실행 시간 순서 아님):

- `a_fundingmode_acct.(a_fundingmode_acct)` → `c_validcombination.(c_validcombination_id)` (`afundingmodevc_afundingmodeacc`).
- `a_fundingmode_acct.(c_acctschema_id)` → `c_acctschema.(c_acctschema_id)` (`cacctschema_afundingmodeacct`).
- `c_acctprocessor.(c_acctschema_id)` → `c_acctschema.(c_acctschema_id)` (`cacctschema_cacctprocessor`).
- `c_acctprocessorlog.(c_acctprocessor_id)` → `c_acctprocessor.(c_acctprocessor_id)` (`cacctprocessor_log`).
- `c_acctschema_default.(c_acctschema_id)` → `c_acctschema.(c_acctschema_id)` (`cacctschema_default`).
- `c_acctschema_default.(ch_revenue_acct)` → `c_validcombination.(c_validcombination_id)` (`chrevenue_cacctschemadefault`).
- `c_acctschema_default.(c_receivable_services_acct)` → `c_validcombination.(c_validcombination_id)` (`creceivableservices_cacctschem`).
- `c_acctschema_default.(p_averagecostvariance_acct)` → `c_validcombination.(c_validcombination_id)` (`paveragecostvariance_cacctsche`).
