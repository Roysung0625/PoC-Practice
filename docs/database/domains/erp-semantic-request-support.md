# 요청·지원·이슈 — 근거 기반 분류안·공식 분류 아님

[전체 일람](../index.md)

분류 근거: 원본 사전 Name/Description + 주요 열/물리 FK 교차대조(문서 overlay 자동 규칙). 물리적 연결과 업무 의미의 확정은 구분합니다.

요청 유형/상태·지원 기록·관련 통지/이슈 참조를 탐색합니다.

관계 흐름 근거(실제 물리 FK의 자식 → 부모; 실행 시간 순서 아님):

- `c_rfq.(c_rfq_topic_id)` → `c_rfq_topic.(c_rfq_topic_id)` (`crfqtopic_crfq`).
- `c_rfq_topicsubscriber.(c_rfq_topic_id)` → `c_rfq_topic.(c_rfq_topic_id)` (`c_rfqtopic_subscriber`).
- `c_rfqline.(c_rfq_id)` → `c_rfq.(c_rfq_id)` (`crfq_crfqline`).
- `c_rfqlineqty.(c_rfqline_id)` → `c_rfqline.(c_rfqline_id)` (`crfqline_crfqlineqty`).
- `c_rfqresponseline.(c_rfqline_id)` → `c_rfqline.(c_rfqline_id)` (`crfqline_crfqresponseline`).
- `c_rfqresponselineqty.(c_rfqlineqty_id)` → `c_rfqlineqty.(c_rfqlineqty_id)` (`crfqlineqty_crfqresplineqty`).
- `c_rfqresponselineqty.(c_rfqresponseline_id)` → `c_rfqresponseline.(c_rfqresponseline_id)` (`crfqresonseline_qty`).
- `r_issueknown.(r_issuerecommendation_id)` → `r_issuerecommendation.(r_issuerecommendation_id)` (`rissuerecommendation_rissuekno`).
