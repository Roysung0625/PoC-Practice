# 재고·창고·로케이터 — 근거 기반 분류안·공식 분류 아님

[전체 일람](../index.md)

분류 근거: 원본 사전 Name/Description + 주요 열/물리 FK 교차대조(문서 overlay 자동 규칙). 물리적 연결과 업무 의미의 확정은 구분합니다.

창고/보관 위치·실사·재고 수량·예약·로트/일련번호의 참조를 탐색합니다.

관계 흐름 근거(실제 물리 FK의 자식 → 부모; 실행 시간 순서 아님):

- `m_demanddetail.(m_demandline_id)` → `m_demandline.(m_demandline_id)` (`mdemandline_mdemanddetail`).
- `m_demandline.(m_demand_id)` → `m_demand.(m_demand_id)` (`mdemand_mdemandline`).
- `m_inventory.(m_perpetualinv_id)` → `m_perpetualinv.(m_perpetualinv_id)` (`mperpetualinv_minventory`).
- `m_inventory.(m_warehouse_id)` → `m_warehouse.(m_warehouse_id)` (`mwarehouse_minventory`).
- `m_inventory.(reversal_id)` → `m_inventory.(m_inventory_id)` (`reversal_minventory`).
- `m_inventoryline.(m_inventory_id)` → `m_inventory.(m_inventory_id)` (`minventory_minventoryline`).
- `m_inventoryline.(m_locator_id)` → `m_locator.(m_locator_id)` (`mlocator_minventoryline`).
- `m_inventoryline.(reversalline_id)` → `m_inventoryline.(m_inventoryline_id)` (`reversalline_minventoryline`).
