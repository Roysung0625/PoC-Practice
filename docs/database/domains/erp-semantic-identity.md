# 사용자·인증·접근 권한 — 근거 기반 분류안·공식 분류 아님

[전체 일람](../index.md)

분류 근거: 원본 사전 Name/Description + 주요 열/물리 FK 교차대조(문서 overlay 자동 규칙). 물리적 연결과 업무 의미의 확정은 구분합니다.

사용자/역할·인증 자격·기록/조직 접근 제한의 참조를 탐색합니다. 현재 계정 권한이 안전하다는 인증은 아닙니다.

관계 흐름 근거(실제 물리 FK의 자식 → 부모; 실행 시간 순서 아님):

- `ad_authorizationaccount.(ad_authorizationcredential_id)` → `ad_authorizationcredential.(ad_authorizationcredential_id)` (`adauthorizationcredential_adau`).
- `ad_authorizationcredential.(ad_authorizationprovider_id)` → `ad_authorizationprovider.(ad_authorizationprovider_id)` (`adauthorizationprovider_adauth`).
- `ad_authorizationscopeprov.(ad_authorizationprovider_id)` → `ad_authorizationprovider.(ad_authorizationprovider_id)` (`adauthorizationprovauthscopepr`).
- `ad_column_access.(ad_role_id)` → `ad_role.(ad_role_id)` (`adrole_adcolumnaccess`).
- `ad_document_action_access.(ad_role_id)` → `ad_role.(ad_role_id)` (`adrole_addocumentactionaccess`).
- `ad_form_access.(ad_role_id)` → `ad_role.(ad_role_id)` (`adrole_adformaccess`).
- `ad_infowindow_access.(ad_role_id)` → `ad_role.(ad_role_id)` (`adrole_adinfowindowaccess`).
- `ad_ldapaccess.(ad_ldapprocessor_id)` → `ad_ldapprocessor.(ad_ldapprocessor_id)` (`adldapprocessor_adldapaccess`).
