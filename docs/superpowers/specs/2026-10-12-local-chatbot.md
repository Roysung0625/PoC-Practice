# Windows 로컬 분석 챗봇 설계

목표는 기간·제품군에 대한 매출, 이익, 판매자 수 질문을 검토 가능한 SQL 계획으로 바꾸고, 사용자가 승인한 뒤 실제 PostgreSQL 결과를 표와 그래프로 확인하는 것이다. 후속 질문은 이전 문맥을 계승하되 적용 조건을 다시 보여준다.

## 확정한 구성

- Vue 3 + TypeScript 화면, Laravel 13 대화·계획 이력, Python 3.13 FastAPI SQL API·AWS 어댑터·Plotly·수신기, PostgreSQL 18 Windows 서비스. Python은 프로젝트 가상환경을 사용한다.
- TPC-H SF1의 8개 테이블을 DuckDB로 생성하여 PostgreSQL에 적재한다. 메타데이터에 테이블·열·관계·날짜 범위·제품군 값을 포함한다.
- AWS 경로는 AgentCore/Bedrock → Lambda → SQS → Windows 수신기 → FastAPI/PostgreSQL → DynamoDB → 같은 Lambda 호출의 응답이다. Agent가 결과 테이블을 폴링하지 않는다.
- 이번 단계는 전체 로컬 구성과 AWS 경계 어댑터를 구현한다. AWS 배포와 유료 호출은 하지 않는다. 고정 샘플 계획은 명확하게 표시하고 실제 로컬 DB에서 실행한다. 자연어 계획·수정은 실제 Agent가 연결되지 않으면 미구성 상태로 응답한다.
- 공통 모델과 예산 정책은 기존 `aws/config`를 읽는다. 모델 자동 대체와 API 과금 우회는 없다. 정확한 비용 상한이 요구되지만 미보장인 설정에서는 `COST_POLICY_BLOCKED`를 반환한다. 구현 중 별도 AWS 작업에서 지연된 월 25 USD 초과 자동 차단이 승인되어 공통 정책이 갱신되었다. 로컬 앱은 최신 정책을 읽으며 이 작업 자체에서는 유료 AWS 호출을 하지 않는다.

## 계획과 승인

- 해석, 적용 조건, 지표 정의, 누락 데이터, 가정, 답변 계획, SQL 계획, SQL/매개변수, 검증 결과, 출처를 보여준다. 내부 사고과정을 생성·표시하지 않는다.
- 실제 순이익은 비용 데이터가 충족될 때만 사용할 수 있다. 샘플에서는 매출과 공급원가 차이를 대체 지표로 명시하고 supplier를 공급업체 수로 명시한다. 임의로 순이익·판매자로 확정하지 않는다.
- SQL은 계획당 한 SELECT. 자연어 수정은 새 revision이며 이전 승인은 무효다. SQL 오류 수정도 다시 승인한다.
- Python이 SQL·매개변수·스키마 버전·revision을 포함한 계획의 SHA-256을 생성한다. 승인된 스냅샷과 실제 실행 요청이 일치해야 한다. 승인 직후 요청 만료 시각을 발급한다.
- Laravel SQLite는 대화·revision·승인 이력의 기준 저장소다. Python SQLite는 작업·승인 사본·중복 방지·전송 outbox만 보관한다. 재시작 시 실행 중이던 작업은 불명 상태로 남기며 자동 재실행하지 않는다.

## SQL과 운영 제한

- localhost 수신, DB 읽기 전용 계정, SQLGlot AST 검사, 허용 테이블·함수, 다중문/변경문/잠금/시스템 객체 차단.
- SQL 전체 트랜잭션 최대 20초, API 25초, 반환 500행/256KiB, 동시 DB 조회 2개. 실패를 빈 결과로 바꾸지 않는다. 금액 원본은 Decimal 문자열로 유지한다.
- 요청 TTL 60초, SQS visibility 90초/long poll 20초, Lambda 대기 65초/timeout 75초, Agent 도구 90초/활성 단계 180초. 사람의 승인 대기 시간은 포함하지 않는다.
- 결과를 저장한 후 SQS 삭제. 중복 요청은 재조회하지 않는다. 만료 요청은 실행하지 않는다. 결과 전송 실패는 저장한 결과만 재전송한다.
- 시작·중지·상태·연결 점검·로그·재접속 문서를 제공한다. 로그인 세션 실행만 검증하며 무인 운영을 완료로 표시하지 않는다.

## 완료 판단

테스트 우선 구현과 실제 PostgreSQL 통합 검증, Laravel API 시험, Vue UI 시험·빌드, 실제 브라우저의 샘플 승인→표·그래프 흐름을 확인한다. AWS 모의 검증과 실연결 미검증을 구분한다. 현재 폴더는 Git 저장소가 아니므로 커밋·푸시·Git 초기화를 하지 않는다.
